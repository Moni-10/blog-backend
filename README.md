# Blog Backend API

Backend API for managing blog content, authentication, and image uploads.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- REST API
- JWT Authentication
- Multer for file uploads
- PM2 for production process management
- Nginx as reverse proxy
